

Програма для візуального моделювання руху частинки під дією синусоїдальної сили F(t) = F0 * sin(2 * pi * f * t) мовою C++ з використанням графічної бібліотеки SFML 3.

## Технології
- Мова: C++17
- Графічна бібліотека: SFML 3
- Система збирання: CMake (v3.20+)
- Пакетний менеджер: vcpkg

## Керування
- Space — Пауза / Симуляція
- R — Перезапуск симуляції
- Up / Down — Збільшити / зменшити амплітуду сили (F0)
- Right / Left — Збільшити / зменшити частоту (f)

## Збирання та запуск

1. Клонувати репозиторій:
   git clone <посилання_на_репозиторій>
   cd <назва_папки>

2. Скомпілювати та запустити через Visual Studio:
   - Відкрити папку проєкту через File -> Open -> Folder...
   - Дочекатися конфігурації CMake та vcpkg
   - Виконати збірку (Ctrl+Shift+B) та запустити ParticleSimulation.exe (F5)

## Структура проєкту
- CMakeLists.txt          # Налаштування CMake
- CMakePresets.json        # Інтеграція з vcpkg
- vcpkg.json              # Залежності (SFML)
- main.cpp                # Головний код програми
- README.md               # Документація
- resources/fonts/arial.ttf # Шрифт для UI
